# project-memory

Аргумент: `$ARGUMENTS`

Сведения о проекте хранятся в графе MCP Memory (сервер `memory`) как одна сущность:

- `name`: `project:<имя папки проекта>`, например `project:prova`. Имя папки — последняя часть рабочего каталога.
- `entityType`: `project`.
- `observations`: ровно три строки с фиксированными префиксами. По этим префиксам `recall` их находит, а `save` заменяет:
  - `Название: …`
  - `Назначение: …`
  - `Технологии: …`

Отвечай пользователю на том языке, на котором он пишет (по умолчанию по-русски).

## Если аргумент `save`

1. **Изучи проект.**
   - Сначала прочитай `README.md`, если он есть.
   - Затем прочитай `CLAUDE.md` и манифесты зависимостей, которые найдутся: `requirements.txt`, `pyproject.toml`, `package.json`, `go.mod`, `Cargo.toml` и т. п.
   - Через Glob посмотри структуру проекта и бегло прочитай главные файлы кода: точку входа, модуль работы с БД, базовый шаблон.
   - Не читай `.env`, файлы с секретами, `.venv`, `node_modules` и файлы баз данных.
2. **Сформулируй три факта**, каждый одной строкой:
   - **Название** — как проект называет себя сам: заголовок README, название в интерфейсе или в `CLAUDE.md`. Если такого названия нет, возьми имя папки.
   - **Назначение** — одно-два предложения о том, что делает проект и для кого он.
   - **Технологии** — язык, фреймворки, хранилище, ключевые библиотеки и внешние сервисы через запятую. Только то, что реально используется в коде, без версий.
3. **Сохрани факты в MCP Memory.**
   - Вызови `mcp__memory__open_nodes` с именем `project:<папка>`.
   - Если такой сущности нет, создай её через `mcp__memory__create_entities` с тремя наблюдениями.
   - Если сущность уже есть, удали через `mcp__memory__delete_observations` её старые наблюдения с префиксами `Название:`, `Назначение:`, `Технологии:` и добавь новые через `mcp__memory__add_observations`. Остальные наблюдения не трогай.
4. **Покажи пользователю**, что сохранено: три строки и имя сущности.

## Если аргумент `recall`

1. Вызови `mcp__memory__open_nodes` с именем `project:<папка>`.
2. Если сущность не нашлась, вызови `mcp__memory__search_nodes` с запросом `project:` и покажи найденные проекты.
   - Если ничего нет, скажи, что для этого проекта ещё ничего не сохранено, и предложи выполнить `/project-memory save`.
3. Покажи сохранённое как есть, коротким списком: **Название**, **Назначение**, **Технологии**. Если есть другие наблюдения, перечисли их ниже.
   - Ничего не дополняй из своих догадок или из текущих файлов: recall показывает только то, что лежит в памяти.

## Если аргумент пустой или другой

Кратко объясни использование: `/project-memory save` сохраняет сведения о проекте, `/project-memory recall` показывает сохранённое.
